# NGE fidelity and VSim adaptations

Upstream is pinned in `upstream.yaml`; its MIT licence is retained as
`LICENSE.upstream`.  “Local” paths below are relative to this directory.

| Paper / pinned upstream behaviour | Local counterpart | Why it differs, and expected effect | Status | Validation |
|---|---|---|---|---|
| Species is `(graph, controller)`; eliminate the worst fraction and choose mutation parents uniformly from survivors (`evolution/species_bank.py`) | `population.py` | Direct translation. Fitness and genealogy remain attached to stable species IDs. | faithful | `test_nge.py` |
| Add-Node, Add-Graph/self-cross, Del-Graph and Pert-Graph | `graph.py` | The arbitrary MuJoCo tree is constrained to the common eight-slot typed grammar. Perturbation crosses discrete type categories instead of adding Gaussian noise to continuous XML attributes. This changes the search space but is required for every comparator to design the same bodies. | faithful adaptation | `test_nge.py` |
| Initial structures are generated independently | `NGEGraph.canonical`; `Population.initial` | The benchmark contract requires every method to begin at `[1,4,6]`. Controllers still receive independent native random initialisations (`seed + species_id`). This removes an initial-body confound. | protocol adaptation | `test_nge.py` |
| NerveNet++ observation embedding, attribute embedding, graph messages, GRU state across environment time, shared node output model, Gaussian policy (`network/nervenetplus_policy.py`) | `nervenet.py:NerveNetPlusPlus` | TensorFlow 1 is translated to PyTorch. VSim exposes root/module observations in a padded vector, which is split back into graph nodes. Caps have no actuator, so cap type is an attribute of the terminal controlling node. | faithful | `test_nge.py` |
| NerveNet++ truncated recurrent backpropagation, length 4 | `NerveNetPlusPlus.forward_sequence`; `training.py:_ppo_update` | Direct translation to four-step sequence minibatches. Hidden state is cleared at VSim episode boundaries. | faithful | `test_nge.py`, `test_benchmark_evaluate.py` |
| Separate two-layer fully connected value baseline and PPO defaults (`agent/optimization_agent.py`) | `nervenet.py:ValueNetwork`; `training.py:_ppo_update` | Direct PyTorch translation: gamma .99, GAE .95, clip .2, 10 epochs, Adam 3e-4, adaptive KL learning rate. | faithful | `test_nge.py` |
| Parent policy, baseline, running observation statistics, and adaptive policy learning rate initialise a child (`evolution/species2species.py`; `agent/evolution_agent.py`) | `ControllerState.inherited_copy`; `SpeciesLearner.inherited_copy`; `NGETrainer._inherit_after_selection` | All graph-independent controller tensors and the parent's current learning rate copy exactly. Optimizer moments reset at generation rebuild, as in the pinned worker reconstruction; resetting the adaptive rate itself would create a non-upstream PPO shock. | faithful | `test_nge.py` |
| GM-UC attribute-only graph regressor, L2 labels, one inference-dropout mask for all proposals, Gumbel ranking (`agent/pruning_agent.py`) | `gm_uc.py` | Direct PyTorch translation. History keeps the latest label for each persistent species ID, matching the upstream dictionary. | faithful | `test_nge.py` |
| MuJoCo/dm_control workers collect about 2,000 serial transitions per species update and species ranking uses completed raw episode returns | `AntNGEEnv`; `training.py:_collect_rollout`; `training.py:_evaluate_population_for_selection` | Each PPO batch uses 64 VSim envs/species × 32 ticks = 2,048 transitions. Those wide rollouts lack enough temporal depth to guarantee an episode finish, so the paid twentieth batch is instead a selection-only pass using 2 envs/species × 1,024 ticks. The controllers and normalisers are frozen and stochastic controller samples are retained. Each species is ranked by exactly the first completed return from each of its two lanes; later auto-reset episodes and partial fragments receive no ranking weight, although all fixed-window transitions remain charged. Thus 19 PPO batches plus selection retain the old 40,960 transitions/species/generation and exact global budget, while one of the upstream 20 PPO updates is traded for equal-count complete-return ranking. | simulator/protocol adaptation | `test_nge.py` config/accounting/collector tests; native VSim smoke pending |
| Graphs are converted to MuJoCo XML and evaluated there | `envs/ant_envs/ant_nge.py` | Required VSim port. Reward, termination, grammar and physics settings are exactly the shared benchmark task; numerical dynamics necessarily differ from MuJoCo. | simulator adaptation | native VSim smoke pending |
| Upstream pruning settings expose Add/Delete mass and assign the remainder to Perturb; Add-Graph is the self-cross branch | `configs/benchmarks/nge.yaml` | Add mass is split into Add-Node .15 and Add-Graph .15, Delete is .15, and the remaining .55 is Pert-Graph. All four primitives are always active and the categorical mass sums to one. | resolved configuration | config validation |
| Upstream saves selected species files but not a complete optimizer/RNG boundary | `training.py:checkpoint_state` | Expanded to satisfy the benchmark contract: every survivor, controller, value net, optimizers, normalisers, GM-UC model/data, counters and RNGs are stored between generations. This affects reproducibility, not learning. | fidelity extension | native CUDA save/resume test pending |
| Upstream training logs native fitness but has no shared cross-method progress metric | `training_evaluation` in `nge.yaml`; `training.py:_run_training_evaluation`; `evaluate.py:evaluate_return` | Optional monitoring runs the common deterministic complete-episode evaluator at configured generation boundaries and logs `rewards/step_eval`. Its separate simulator work is not learning data, is not added to the training budget, and all training RNG state is restored afterwards. Disabled by default. | benchmark instrumentation | `test_nge.py`, `test_benchmark_evaluate.py` |
| Native output is the surviving population | `method.py` | Evaluation samples surviving species uniformly with replacement and routes each body to its own recurrent controller. No champion is substituted. | faithful | `test_nge.py` |

The label is gated by these checks. A native GPU smoke run remains required on
the target VSim machine before paper-scale jobs begin; CPU tests cannot validate
VSim dynamics or CUDA resume determinism.
